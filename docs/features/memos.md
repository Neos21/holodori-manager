# メモ管理

`/memos` で提供する複数メモの管理と、共通サイドメニューに表示するデフォルトメモの仕様を示す。API パスと共通契約は [../api.md](../api.md) を参照のこと。


## デフォルトメモ

`memos.id = 1` は必ず存在するデフォルトメモとして扱い、物理削除を許可しない。ログイン後の共通サイドメニューではデフォルトメモだけを表示し、内容に変更がある場合は Blur 時に保存する。


## メモ管理ページ

メモ一覧を `memos.id ASC` で取得し、初期表示では ID 1 を編集対象とする。画面には次を順に表示する。

1. メモ ID を切り替えるボタン一覧
2. 編集中 ID と保存・削除ボタン
3. メモ本文のテキストエリア
4. 新規追加ボタン

新規追加後は作成されたメモを編集対象とする。ID 1 以外のメモを削除した後は、ID 1 を編集対象とする。物理削除による ID の欠番は詰めず、そのまま表示する。


## 未保存の変更

フォームの本文と編集対象の保存済み本文が異なる場合を、未保存の変更がある状態とする。未保存の変更がある状態で別の ID へ切り替える、新規追加する、または別ページへ遷移する場合は、`window.confirm()` で変更を破棄するか確認する。


## デフォルトメモの同期

サイドメニューとメモ管理ページは、メモ一覧のインメモリキャッシュを共有する。一方で保存前の入力内容はそれぞれのコンポーネント内だけで保持し、一方で ID 1 の保存に成功した時点で他方へ保存済みの内容を反映する。

メモ管理ページで ID 1 を編集中にサイドメニューから ID 1 が保存された場合は、メモ管理ページに未保存の変更があっても確認せず破棄し、サイドメニューで保存された内容へ置き換える。
