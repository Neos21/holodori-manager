# ホロワーク管理

`/holoworks` で提供する現行の画面・候補選定・操作仕様を示す。ゲーム共通の計算規則は [../domain.md](../domain.md)、API パスと共通契約は [../api.md](../api.md) を参照のこと。


## 対象データ

- 枠一覧にはすべての `holoworks` を表示する
- ホロメン別ステータスには `holomems.is_active = 1` のホロメン (卒業等していない・ゲーム内で使用可能) だけを表示する
- 開始候補からは、卒業済みまたはいずれかの枠で活動中のホロメンを除外する
- 活動中メンバーの表示や、ホロメン関連の基本順序は `holomems.sort_order ASC`、`holomems.id ASC` とする


## 画面構成

画面には次を順に表示する。

1. ホロワーク枠一覧
2. ホロメン別の達成状況・活動状況・黄マス集計一覧
3. ホロワーク枠追加ボタン

一覧は横幅を超える場合に横スクロールできる構成とし、操作可否に関わらず各操作ボタンを同じ位置に表示する。


## ホロワーク枠一覧表

| 列             | 内容                                      |
|----------------|-------------------------------------------|
| 枠の名前       | `holoworks.name`                          |
| 活動中メンバー | グループとタレント名。1人ずつ改行表示する |
| 開始           | 活動中メンバーがいない場合だけ実行できる  |
| 完了           | 活動中メンバーがいる場合だけ実行できる    |
| 中断           | 活動中メンバーがいる場合だけ実行できる    |
| 削除           | 活動中メンバーがいない場合だけ実行できる  |

各操作の Submit 中は、同じ操作 UI のボタンを非活性にして二重送信を防ぐ。枠一覧上の完了・中断・削除では、処理中に枠一覧の操作ボタンと枠追加ボタンを一律に非活性にし、ホロメン別ステータス一覧から編集モーダルを開く操作も受け付けない。


## ホロメン別ステータス一覧表

| 列                       | 内容                                  |
|--------------------------|---------------------------------------|
| グループ                 | `holomems.group_name`                 |
| タレント名               | `holomems.name`                       |
| 現在回数                 | `holowork_achievements.current_count` |
| 次回閾値                 | 全達成済みの場合は `-`                |
| 残り回数                 | 全達成済みの場合は `-`                |
| キューブ獲得アップ量     | 解放済み黄マスの合計最終レート        |
| 特訓アイテム獲得アップ量 | 解放済み黄マスの合計最終レート        |
| レッスン Pt 獲得アップ量 | 解放済み黄マスの合計最終レート        |
| ホロメンメモ             | `holomems.note`                       |

合計最終レートは小数第2位まで固定表示する。現在回数のセルからホロワーク達成状況編集モーダル、1行に省略表示したホロメンメモのセルからホロメンメモ編集モーダルを開く。活動中メンバーは行の背景色で表現する。


## 枠追加

枠追加ボタンからモーダルを開き、枠名を入力する。共有の `holoworkSchema` で検証し、追加成功後はモーダルを閉じて枠一覧を再取得する。


## 達成状況編集

- グループとタレント名を読取専用で表示する
- 現在回数は 0 以上の整数とする
- 更新を許可する項目だけに限定した共有 Schema で検証する
- 更新成功後はモーダルを閉じ、メンバー状況だけを再取得する
- 更新失敗時はモーダルを維持し、フォーム内にエラーを表示する


## ホロメンメモ編集

ホロメン別ステータス一覧のホロメンメモをクリックすると、ボード管理ページと共通の編集モーダルを開く。更新対象のグループとタレント名を読取専用で表示し、`holomems.note` を更新する。更新成功後はモーダルを閉じ、メンバー状況だけを再取得する。


## メンバー選択と並び順

枠一覧の「開始」を押すと、その枠を開始対象とし、ホロメン一覧左端のチェックボックスを活性化する。活動中メンバーは背景色で表示区別し、選択できない。選択中は他の枠操作・枠追加・メンバー編集を無効化する。

- 1人以上5人以下を選択し、両テーブルの間の「開始する」で確定する
- 5人選択済の場合は未選択のチェックボックスだけを非活性にする
- 5人未満で開始する場合は `window.confirm()` で確認する
- 「キャンセル」で開始対象と選択を解除する
- 開始成功後は一覧を再取得せず、枠の活動中メンバーとホロメン一覧の活動状況を更新する

一覧は初期状態でホロメン表示順・ID 順とする。キューブ・特訓・レッスンの列見出しで各増量率の降順、残数の列見出しで残り回数の昇順に切り替える。同値はホロメン表示順・ID 順とし、残数が `-` の達成済みメンバーは末尾に置く。選択中も並べ替えができ、選択状態を維持する。


## 完了・中断・削除

- ホロワークを「完了」すると、対象枠で活動中メンバー全員の回数が 1 増えて解放される (任意の枠で選択可能な状態に戻る)
- ホロワークを「中断」すると、対象枠で活動中メンバー全員が解放され、完了回数が増えない
- ホロワーク枠を「削除」する際は、対象枠を本当に削除するかどうか `window.confirm()` で確認のうえ物理削除する
- 完了・中断の成功後は一覧を再取得せず、枠の活動中メンバーを空にしてメンバーの活動状況を解除する
- 完了時は現在回数を加算し、共有計算処理で次回閾値と残数を更新する
- 削除成功後は一覧を再取得せず、枠を一覧から除く


## サーバ側の整合性

クライアントの表示状態を信用せず、操作確定時に次を検証する。

- 対象枠が存在する
- 活動中メンバーがいる枠を再開始・削除しない
- 活動中メンバーがいない枠を完了・中断しない
- 開始メンバーが1人以上5人以下で、ID が正の整数かつ重複していない
- 開始メンバーが存在し、卒業済みでなく、他枠でも活動中でない

ページ表示後に状態が変わった場合も開始時の再検証で検出する。開始と完了の複数書き込みには D1 の `batch()` を使い、一部のメンバーだけが更新される途中状態を残さない。
