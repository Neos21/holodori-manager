# ホロメンボード管理

`/board-nodes` で提供するボードマスの一覧・単体編集・一括追加仕様を示す。ゲーム共通のカテゴリと効果量の計算規則は [../domain.md](../domain.md)、API パスと共通契約は [../api.md](../api.md) を参照のこと。


## 画面構成

ボードマスをカテゴリ順、ホロメン表示順、マス ID 順で一覧表示する。画面下部には「黄マス一括追加」「緑マス一括追加」「新規マス追加」ボタンをこの順に表示する。

各マスの編集ボタンから単体編集モーダルを開く。ホロメンメモからはホロメン管理と共通の編集モーダルを開く。


## 単体の新規追加・編集

新規追加ではホロメン、カテゴリ、カテゴリに応じた項目、効果量、解放状況を入力する。編集ではホロメン、カテゴリ、黄マスの報酬アップ対象アイテムを変更できない。更新成功後はモーダルを閉じてボードマス一覧だけを再取得する。


## 黄マス一括追加

初期表示では、キューブ、特訓アイテム、レッスン Pt を選択した行をそれぞれ5行ずつ表示する。各行のマス効果には対象アイテムの表示名を初期値として設定し、対象アイテムを変更した場合も連動して更新する。

報酬アップ対象アイテム、マス効果の内容、基礎効果量がすべて入力された行だけを追加対象とする。行追加では、これらの項目が未入力の行を末尾に追加する。


## 緑マス一括追加

初期表示では、次の6行を基礎効果量 `0.50` で表示する。

- ホッピン・ロープ
- そろえてクッキング
- メガサーキット
- ポカジャン！
- ホロゴールド
- メンバー Exp

マス効果の内容と基礎効果量がともに空欄の行は追加対象から除外する。片方だけが入力された行は入力エラーとする。行追加では両項目が未入力の行を末尾に追加する。


## 一括書き込み

一括追加対象の全行を共有 Schema で検証してから、D1 の `batch()` で同一トランザクションとして作成する。一部の行だけが作成された状態は残さない。追加成功後はモーダルを閉じてボードマス一覧だけを再取得する。
