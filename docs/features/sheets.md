# スプレッドシート

`/sheets` で提供する Univer Sheets を利用したスプレッドシートの仕様を示す。API パスと共通契約は [../api.md](../api.md) を参照のこと。


## ワークブック

画面ではアプリケーション上の ID 1 に対応する単一ワークブックを扱う。初回表示時にワークブックが保存されていない場合は、200行・20列のシートを1枚持つ空のワークブックを作成する。

ワークブック内では複数のシートを作成・削除できる。セルの文字・背景色、罫線、配置、結合に加えて、セルの値に基づく条件付き書式を利用できる。


## 自動保存

セル、書式、シート構成など、ワークブックスナップショットに保存されるデータを変更した場合は、最後の変更から2秒後にワークブック全体を自動保存する。画面上部には保存待ち、保存中、保存済み、保存失敗の状態を表示する。

保存中に追加の変更が行われた場合、その変更は次回の自動保存対象として残す。保存に失敗した場合はエラーと再保存ボタンを表示する。

保存待ち、保存中、または保存失敗の状態で別ページへの遷移、再読込、タブ終了を行おうとした場合は、未保存の変更が破棄されることを確認する。

ズーム倍率はワークブックの保存対象から除外し、シートごとにブラウザの LocalStorage へ保存する。サーバへ保存するスナップショットでは 100% に正規化し、スマートフォンと PC など異なるブラウザ間で倍率を共有しない。


## 初期表示

Univer のライブラリ読込中からワークブックの初回描画が終わるまで、ページ領域全体に半透明の背景とスピナーを表示する。Univer の初回読込に時間がかかり、空白の画面が表示され続ける時間が長かったため。


## モバイル表示

スプレッドシートを開いた時点で、画面幅が 1024px 未満、タッチポイントが1つ以上、かつモバイル端末の UA に該当する場合は、Univer のモバイル UI を使用する。iPadOS のデスクトップ用 UA もモバイル端末として扱う。条件を満たさない場合はデスクトップ向けの通常 UI を使用する。

モバイル UI はタッチ操作に適したプラグインモードで構成し、デスクトップ UI は従来のプリセットモードを維持する。画面サイズや端末情報を変更した場合は、ページを再読込した時点で UI を再判定する。
