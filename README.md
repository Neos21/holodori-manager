# Holodori Manager

スマホゲーム「ホロドリ (hololive Dreams)」における育成状況・ホロワークの管理を省力化する、個人利用向け Web アプリ。


## 主な機能

- ホロメンの表示順・在籍状況・自由記入欄の管理
- 所有カードと育成状況の管理
- ホロメンボードのマス解放状況と効果量の管理
- ホロワークの開始・完了・中断、アチーブメント進捗、報酬アップ量に基づく候補選択
- ミニゲーム「High & Low」のポーカー保持、ダブルアップ、日次収支の計算支援
- 自由メモ (ログイン後の共通サイドメニューとメモ管理ページで利用できる)
- スプレッドシート (複数シート、書式、条件付き書式を備えた単一ワークブック)


## 技術スタック

- フロントエンド : React + React Router (SPA モード)
- UI : Tailwind CSS + daisyUI
- State 管理 : Zustand
- HTTP クライアント : ky
- バリデーション : Zod
- バックエンド : Hono (TypeScript)
- ビルドツール : Vite
- 実行環境 : Cloudflare Workers
- DB : Cloudflare D1 (SQLite)
- 認証 : 環境変数に注入したパスワードと照合して JWT を発行し、LocalStorage に保持する。単一ユーザ専用アプリのためユーザテーブルは持たない


## 開発の開始

```bash
$ npm install
$ npm run dev
```

開発手順、検証コマンド、D1・デプロイ操作は [CONTRIBUTING.md](./CONTRIBUTING.md) を参照のこと。

## ページ一覧

| パス                       | 機能                                                                         |
|----------------------------|------------------------------------------------------------------------------|
| `/`                        | ログイン。ログイン済みの場合は `/home` に遷移する                            |
| `/home`                    | ログイン後のホーム。共通サイドメニューはこのページへの遷移後に初めて表示する |
| `/holomems`                | ホロメン管理                                                                 |
| `/cards`                   | カード管理                                                                   |
| `/board-nodes`             | ホロメンボード管理                                                           |
| `/holoworks`               | ホロワーク管理                                                               |
| `/high-and-low-calculator` | High & Low 計算                                                              |
| `/memos`                   | メモ管理                                                                     |
| `/sheets`                  | スプレッドシート                                                             |

共通サイドメニューには各ページへのリンクと自由メモを表示する。スマートフォンではハンバーガーメニューで開閉する。
